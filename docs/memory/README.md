# 进度记忆更新流程（轻量版）

## 适用时机
- 每个阶段完成并测试通过后。
- 每个组件完成并测试通过后。

## 必做步骤
1. 在 `docs/memory/components-progress.md` 的“已完成组件”追加一行完成记录。
2. 在“测试状态”更新该组件最新结果，并补齐测试证据（命令、日志或 CI 链接）。
3. 在“兼容性备注”写明对齐状态与差异，不允许空白。
4. 在“下一组件队列”把下一个要做的组件提升到最高优先级，并写清前置条件与 DoD。
5. 在文件末尾按模板追加一段详细记录，确保下次可直接续做。

## 记录原则
- 只记录“已验证事实”，不写猜测。
- 未有测试证据不得标记“完成”。
- 如果发现 API 不合理或需求不清晰，先提问再推进，不自行假设。
- 组件库优先复用公共能力，避免引入一次性实现与废代码。
